# arduino-led-chaser
Arduino LED chaser project where multiple LEDs light up sequentially to create a running light effect.

## What It Does

The LEDs turn on and off sequentially to create a continuous running light effect.

## Components Used

Arduino Uno, LEDs, resistors, breadboard, and jumper wires.

## How It Works

The Arduino controls each LED using digital output pins. Each LED turns on for a short time before moving to the next one.

## What I Learned

I learned how to control LEDs using Arduino, use digital output pins, write basic Arduino code, and build a simple circuit on a breadboard.
